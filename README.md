# zhou-weichen.github.io

Personal academic homepage of **Weichen Zhou (周蔚琛)** — MSc student in Mathematical
Informatics at the University of Toyama (KiZulab).

Live at https://zhou-weichen.github.io

Single-file static site (`index.html`, self-contained CSS/JS). The hero features a live
visitor map powered by a small Cloudflare Worker (geolocation + cumulative counts); set
`WORKER_URL` in `index.html` to enable it, otherwise it falls back to demo data.
